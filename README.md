# hx-claude-ide

Editor-awareness plugin that makes **Claude Code** aware of the active file, cursor, and
selection in the [Steel branch of Helix](https://github.com/mattwparas/helix) (`hx-steel`),
using the same lockfile + WebSocket-MCP mechanism as the official VS Code / JetBrains
extensions.

Status: **scaffolding** — see the design note and the T01–T12 implementation tracker in the
knowledge base for architecture, decisions, and task state. Install and usage docs land in T12.
